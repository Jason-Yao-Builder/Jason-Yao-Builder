# Dice Wars — V1（原始版本）

这是最初的 Jupyter Notebook 版本，所有逻辑写在一个 notebook 里。

## 文件

- `dicewar_map_try4displayOK.ipynb` — 游戏主体代码
- `反思与总结.docx` — 开发过程中的反思笔记

## 运行

需要 Jupyter Notebook 环境 + pygame。在 notebook 中**先运行第二个 cell**（类和函数定义），再运行第一个 cell（游戏主循环）。

## 说明

这个版本作为历史存档保留。功能完整但代码结构较为原始，推荐使用 [v2](../v2/) 版本。
